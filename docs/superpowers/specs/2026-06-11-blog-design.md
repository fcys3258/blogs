# 计算数学博客 · 总体设计

**日期**: 2026-06-11  
**状态**: 已确认

## 1. 项目概述

一位计算数学方向的研究生需要一个个人博客，用于分享学习笔记。核心需求：
- 用 Markdown + LaTeX 撰写笔记，框架自动处理排版
- 文章末尾嵌入交互式数值实验区域（函数逼近、差分收敛等可视化）
- 交互组件的计算逻辑由 AI 从 MATLAB 代码翻译为 JavaScript
- 纯静态站点，不需要后端服务器

## 2. 技术选型

| 层 | 选择 | 理由 |
|---|---|---|
| 框架 | **Astro** | 静态生成，Markdown 原生支持，Island 架构让交互组件按需加载 JS |
| 数学公式 | **KaTeX** | 服务端渲染，比 MathJax 快，无页面闪烁 |
| 科学可视化 | **Plotly.js** | 接近 MATLAB 画质，支持缩放/悬停/3D |
| 样式 | **CSS（Astro scoped styles）** | 极简现代风格，大留白，无衬线字体 |
| 部署 | **GitHub Pages / Vercel** | 免费静态托管，推送即部署 |
| 构建 | **Astro 默认（Vite）** | 零配置 |

## 3. 视觉风格

采用 **B 风格 — 极简现代风**：
- 白底/浅灰背景，大量留白
- 系统无衬线字体栈（-apple-system, sans-serif）
- 数学公式为视觉焦点
- 顶栏导航（博客标题 + 标签 + 搜索 + 深色模式切换）
- 文章正文最大宽度 ~680px，居中阅读
- 交互实验区用卡片容器包裹，与正文以分隔线区分

## 4. 内容结构

- **文章组织**：独立文章模式，通过标签分类（#逼近论 #有限差分 #数值代数 等）
- **连续内容**：通过标题手动编号（如 "1-1 Lagrange插值"、"1-2 Newton插值"）体现顺序
- **文件结构**：
  ```
  content/posts/
  ├── function-approximation/
  │   ├── index.md        ← 正文（纯 Markdown + LaTeX）
  │   └── demo.js         ← 文末交互组件
  ├── finite-difference/
  │   ├── index.md
  │   └── demo.js
  └── ...
  ```
- **首页**：文章列表，按时间倒序，支持标签筛选
- **标签页**：按主题聚合文章

## 6. 交互组件方案

- 每个需要交互的文章，在 `demo.js` 中导出一个 Astro-compatible 组件
- 组件接收参数（函数选择、节点、步长等），用户调整参数时 Plotly.js 实时重绘
- 无需后端：所有数值计算在浏览器中完成（math.js / 手写 JS 实现）
- AI 辅助：用户提供 MATLAB 代码，AI 翻译为 JavaScript + Plotly 调用

## 7. 用户工作流

1. 在 `content/posts/<article-slug>/` 下创建 `index.md`，用 Markdown + LaTeX 写正文
2. 将 MATLAB 原型代码提供给 AI，翻译为 `demo.js`
3. 本地 `npm run dev` 预览
4. `git push` → 自动部署

## 9. 约束与假设

- 用户 Web 开发经验介于 A-B 之间（有限 HTML/CSS 基础）
- 后期交互组件的 JS 代码由用户 + AI 协作完成，不在本次搭建范围内
- 首次搭建只包含框架、样式、一篇文章模板（含示例交互组件）
- 部署目标优先选择最简单的方案（GitHub Pages）
